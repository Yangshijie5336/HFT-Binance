## 持久化与真实性说明

- 原始 WebSocket 帧以精确文本保存（仅做 JSON 转义），并记录 run_id、连接代次、接收 UTC/单调时间、序号、payload 字节数和 payload SHA-256。
- raw 与派生文件批量 flush，并按 buffered_batch_flush_fsync_every_100_records_plus_final 及最终确定时 fsync；最终确定错误会如实上报，绝不忽略。
- `PASS` 要求真实 WebSocket 连接、实际采样时长严格达到目标（排空时间不计入）、raw 帧已落盘、SHA-256 一致、零队列溢出、零持久化/处理失败，且无断开、异常帧、重复或乱序成交。
- 合成基准永远不能作为实时网络吞吐证据。策略只输出标签，执行禁用。
